## 新版本亮点 / What's New

- **团队组织支持 / Team organizations**：支持在账号菜单切换组织，查看团队余额与成员预算；对话绑定结算组织并显示团队徽标，首次切换团队时确认隐私提示。The account menu supports organization switching, team balances and member budgets; conversations retain their billing organization and show a team badge, with a privacy confirmation on the first team switch.
- **任务级云端凭证 / Task-scoped cloud credentials**：服务端启用对应能力后，云端回复使用任务绑定的短期 Relay 凭证，子代理继承父任务；兼容旧版个人账户服务端。When enabled by the server, cloud replies use short-lived relay credentials bound to an agent task, and sub-agents inherit the parent task; legacy personal-account servers remain supported.
- **系统凭据存储 / Native credential storage**：会话令牌迁移到 macOS 钥匙串或 Windows 凭据管理器，并修复原生凭据存储未启用的问题。Session tokens move to macOS Keychain or Windows Credential Manager, with native credential storage correctly enabled on both platforms.
- **排队消息立即发送 / Send queued messages immediately**：不支持运行中注入消息的代理也可中断当前回复并立即发送排队消息。Agents without mid-run message injection can now interrupt the current reply and send a queued message immediately.
- **更新与设置提示 / Update and settings prompts**：识别服务端要求升级的响应并触发内置更新检查；调整聊天设置说明与系统提示词标签。Server responses requiring a client upgrade trigger the built-in update check; chat settings descriptions and the system prompt label are clearer.

组织与任务凭证功能取决于服务端能力开关；本版暂不包含自动化固定组织、外部 CLI 独立组织凭证以及佣金与激励摘要。Organization and task-credential features depend on server capability flags; fixed automation organizations, separate organization credentials for external CLIs, and commission or incentive summaries are not included in this release.
