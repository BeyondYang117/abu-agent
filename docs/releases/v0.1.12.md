# v0.1.12

- 日期：2026-10-12
- 主题：团队组织兼容（WS-13 Client Phase A–C）

## 变更

- 新增 `CloudContextManager`：Bootstrap 能力协商、`legacy_mode`、当前组织上下文
- Session Token 迁移到系统钥匙串（macOS Keychain / Windows Credential Manager）；settings 仅保留设备与组织 ID
- 账户菜单支持组织切换、结构化余额 / 成员预算展示（`features.organizations` 开启时）
- 对话绑定结算组织；标题栏显示团队组织徽标；切换团队时首次隐私确认
- 云端回复在 `scoped_relay_credentials` 开启时创建 Agent Task 并使用任务绑定短期 Relay；子代理继承父任务
- 识别 `CLIENT_UPGRADE_REQUIRED`（426）并触发内置更新检查
- 兼容旧服务端：Bootstrap 404/405 或组织开关关闭时行为与个人账户一致

## 不做（后置）

- Phase E：佣金与激励摘要
