## 新版本亮点 / What's New

- **账号安全加固 / Account security hardening** —— 退出登录会同时注销云端会话；在其他设备上撤销某台设备后，它会立即下线；在控制台禁用的桌面令牌不会再被客户端自动恢复。Logging out now also revokes the cloud session; revoking a device from another device signs it out immediately; desktop tokens you disable in the console are no longer silently re-enabled.
- **签到统一到福利中心 / Check-in unified with the welfare center** —— 桌面端签到与网页福利中心共用同一次每日签到，奖励为福利余额，账号菜单同步显示。Desktop check-in now shares one daily check-in with the web welfare center; rewards are welfare balance and the account menu shows them as such.
- **更安全的自动更新 / Safer auto-update** —— 下载安装包后校验 SHA-256，校验文件缺失或不匹配时拒绝安装，并引导手动下载。The updater verifies the installer's SHA-256 after download and refuses to install on a missing or mismatched checksum, pointing you to a manual download instead.
- **网络请求更稳 / More reliable networking** —— 账号相关请求统一设置超时并复用连接，网络异常时不再一直转圈。Account requests now share one connection pool with default timeouts, so a network stall no longer leaves the UI spinning.
- **设备识别稳定 / Stable device identity** —— 设备标识首次生成后本地保存，升级或改机器名后不会被识别成新设备。The device fingerprint is saved after first use, so upgrades or hostname changes no longer register the same machine as a new device.
- **更流畅 / Smoother UI** —— 多图对话、侧栏刷新、切换对话时的文件读取移到后台线程，Windows 上的卡顿明显减少。File reads for multi-image chats, sidebar refreshes and conversation switches moved to background threads, removing most stalls, especially on Windows.
- **Windows 稳定性 / Windows stability** —— 关闭窗口与登录流程更稳定；浏览器无法自动打开时会显示授权链接供手动打开。Closing windows and the login flow are more robust; when the browser cannot be opened, the authorization link is shown for manual use.
- **模型更新 / Model updates** —— 新增 GPT-6 Astra、Claude Fable 5.1 的模型信息，并更新 Claude / Codex 的回退模型列表。Adds GPT-6 Astra and Claude Fable 5.1 metadata and refreshes the Claude / Codex fallback model lists.
