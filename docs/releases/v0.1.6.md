# ABU Agent Desktop v0.1.6

桌面 AI 助手 · macOS (Apple Silicon + Intel) + Windows。Desktop AI assistant for macOS (Apple Silicon + Intel) and Windows.

## 新版本亮点

- **协作目录拖放** —— 聊天窗口支持直接拖入目录，快速为当前任务添加协作目录。
- **模型路由与聊天体验改进** —— 优化模型选择、思考级别和流式聊天交互，并减少重复工具调用。
- **本地 CLI 与外部代理增强** —— 改进 Codex、OpenCode 等本地代理的配置导入、编程模式和会话体验。
- **可靠性与安全性改进** —— 升级 Mermaid 并加入 DOMPurify，提升 Markdown 内容渲染安全性；优化登录引导和慢网络下的启动体验。

## What's New

- **Collaboration directory drag-and-drop** — drop directories directly into chat to add them to the current task.
- **Better routing and chat experience** — improves model selection, thinking levels, streaming interactions, and reduces duplicate tool calls.
- **Stronger local CLI and external-agent support** — improves Codex/OpenCode configuration import, programmer mode, and session handling.
- **Reliability and security improvements** — upgrades Mermaid and adds DOMPurify for safer Markdown rendering, while improving onboarding on slow networks.
