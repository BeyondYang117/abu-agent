# ABU Agent Desktop v0.1.2

桌面 AI 助手 · macOS (Apple Silicon + Intel) + Windows。Desktop AI assistant for macOS (Apple Silicon + Intel) and Windows.

## 下载 / Downloads

- **Windows NSIS 安装包** — `ABU.Agent.Desktop_0.1.2_x64-setup.exe`（installer）
- **Windows MSI 安装包** — `ABU.Agent.Desktop_0.1.2_x64_en-US.msi`（installer）
- **Windows 便携版** — `ABU.Agent.Desktop_0.1.2_x64-portable.zip`（解压即用 / unzip and run `ABU Agent Desktop.exe`）
  - 需要已安装 Edge WebView2（Windows 10/11 通常已有）。Requires the Edge WebView2 runtime.
  - 设置和对话与安装版共用用户目录。Settings and chats are shared with the installed app.
  - 应用内更新仍下载安装包，不会原地覆盖 zip。In-app update still downloads the NSIS installer.
- **macOS Apple Silicon** — `ABU Agent Desktop_0.1.2_aarch64.dmg`（未签名 / unsigned）
- **macOS Intel** — `ABU Agent Desktop_0.1.2_x64.dmg`（未签名 / unsigned）
  - 首次启动：右键 → 打开，或运行 `xattr -cr "/Applications/ABU Agent Desktop.app"`
  - First launch: right-click → Open, or run `xattr -cr "/Applications/ABU Agent Desktop.app"`

## 新版本亮点

- **ABU API 权益与配额** —— 接入 entitlement API，云端运行模式可读取套餐权益与用量；任务配额交由服务端默认策略，避免客户端硬编码单位不一致。
- **自动 Provider 检测** —— Provider 协议默认支持 `auto`，根据 CLI 身份、服务商名称和 endpoint 自动识别 OpenAI、Anthropic、Gemini、xAI 等协议，同时兼容旧配置。
- **用量页更完整** —— 展示任务的订阅、计费组、请求模型和路由信息，并可按任务查看执行轨迹，方便排查云端调用。
- **Relay 会话更稳定** —— 长时间或排队后的云端对话在生成前刷新 relay 凭据，降低凭据即将过期导致失败的概率。
- **配额显示统一** —— 聊天配额提示与用量页共用同一金额格式化逻辑。
- **开发与发布体验** —— npm/Cargo 脚本在 GUI 环境中也能找到 Rust 工具链；macOS 同时发布 Apple Silicon 与 Intel 安装包。

## What's New

- **ABU API entitlements and quotas** — Cloud mode can read plan entitlements and usage; task caps now defer to server defaults instead of relying on client-side hard-coded units.
- **Automatic provider detection** — providers default to `auto` and infer OpenAI, Anthropic, Gemini, xAI, and other protocols from CLI identity, provider name, and endpoint hints while keeping legacy settings compatible.
- **Richer usage details** — the usage view shows subscription, billing group, requested model, and routing metadata, with lazy per-task execution traces for cloud-call debugging.
- **More reliable relay sessions** — long-running or queued cloud conversations refresh their relay credential immediately before generation, reducing failures from nearly expired credentials.
- **Consistent quota formatting** — the chat quota indicator and usage view share the same amount formatter.
- **Smoother development and releases** — npm/Cargo scripts locate Rust from standard GUI environments, and macOS builds now cover both Apple Silicon and Intel installers.
