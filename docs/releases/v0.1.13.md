## 新版本亮点 / What's New

- **修复任务级云端会话 / Fix scoped agent sessions**：云端回复创建 Agent Task 前先调用 `POST /api/agent/sessions`，不再用本地对话 ID 冒充 `session_id`，消除 `invalid agent session`。Cloud replies now create a real agent session before opening a task, instead of fabricating `session_id` from the local conversation id (fixes `invalid agent session`).
- **补齐任务头 / Send X-Abu-Agent-Task-ID**：scoped `aar_` 凭证请求自动附带 `X-Abu-Agent-Task-ID`（含平台搜索），避免 `缺少 X-Abu-Agent-Task-ID`。Requests that use scoped `aar_` credentials now include `X-Abu-Agent-Task-ID` (including platform search), fixing missing-task-header 400s.
- **会话失效自愈 / Stale session recovery**：本地清库或换库后若缓存 session 失效，会自动重建一次再创建任务。If a cached agent session disappears after a local DB reset, the client recreates it once and retries task creation.
