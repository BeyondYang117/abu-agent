# ABU Agent Desktop v0.1.3

桌面 AI 助手 · macOS (Apple Silicon + Intel) + Windows。Desktop AI assistant for macOS (Apple Silicon + Intel) and Windows.

## 新版本亮点

- **ABU API 设备与任务管理** —— 增加 Rust 后端设备注册、凭据配置和任务 API，设备页与用量页可读取更完整的云端状态。
- **一键配置 ABU API 凭据** —— 外部 CLI 设置支持快速完成 ABU API 凭据配置，减少手动复制和配置错误。
- **CLI 凭据与模型筛选更准确** —— 凭据按场景组绑定，relay 模型按 CLI 家族过滤，降低选错模型导致的调用失败。
- **ABU API relay 路由修复** —— relay 请求正确使用 Anthropic Messages 协议，提升云端对话兼容性。
- **版本更新检查修复** —— 修正应用内版本更新判断与发布流程细节。

## What's New

- **ABU API device and task management** — adds Rust-backed device registration, credential configuration, and task APIs with richer cloud status in Devices and Usage.
- **One-click ABU API credentials** — external CLI settings can configure ABU API credentials with a single action.
- **More accurate CLI credentials and model filtering** — credentials are pinned to scenario groups and relay models are filtered by CLI family.
- **Fixed ABU API relay routing** — relay requests now use the Anthropic Messages protocol correctly for better cloud chat compatibility.
- **Improved update checks** — fixes version update detection and release workflow details.
