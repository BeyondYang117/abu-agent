# ABU Agent Desktop v0.1.4

桌面 AI 助手 · macOS (Apple Silicon + Intel) + Windows。Desktop AI assistant for macOS (Apple Silicon + Intel) and Windows.

## 新版本亮点

- **悬浮状态体验升级** —— 新增最小化 Agent 窗口的悬浮状态指示，并重新设计悬浮球，让后台任务状态更直观。
- **Agent 重试更可靠** —— 统一瞬时故障的重试逻辑，在重试过程中提供清晰状态反馈，减少短暂网络异常造成的中断。
- **云端 Relay 架构精简** —— 用统一 relay 凭据替代旧的任务式 relay 流程，简化云端运行链路与凭据管理。
- **CLI 凭据回退修复** —— relay 请求在需要时可回退到 CLI 凭据，提升不同配置场景下的云端调用兼容性。
- **macOS 浮层输入修复** —— 销毁浮层窗口前正确结束输入法会话，避免中文等输入法状态残留。

## What's New

- **Upgraded floating status experience** — adds a floating status indicator for minimized Agent windows and redesigns the floating ball for clearer background-task visibility.
- **More reliable Agent retries** — unifies retry handling for transient failures and shows clear status feedback while recovery is in progress.
- **Simplified cloud relay architecture** — replaces the legacy task-based relay flow with unified relay credentials for a leaner cloud runtime and credential model.
- **Fixed CLI credential fallback** — relay requests can fall back to CLI credentials when needed, improving compatibility across configuration scenarios.
- **Fixed macOS overlay input cleanup** — properly ends the IME session before destroying overlay windows, preventing stale input-method state.
