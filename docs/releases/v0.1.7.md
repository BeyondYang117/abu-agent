# ABU Agent Desktop v0.1.7

桌面 AI 助手 · macOS (Apple Silicon + Intel) + Windows。Desktop AI assistant for macOS (Apple Silicon + Intel) and Windows.

## 新版本亮点

- **翻译窗口体验重构** —— 收敛旧的翻译窗口路径，统一通过 Lens 浮层处理翻译请求，简化窗口生命周期并减少残留状态。
- **翻译交互更顺畅** —— 扩大翻译窗口并优化快速翻译流程，减少不必要的窗口与命令分支。
- **登录与网络容错增强** —— 增加 ABU API 多域名故障转移，并改进认证失败时的回退处理。
- **macOS 浮层稳定性改进** —— 调整浮层层级，避免翻译结果被输入法候选窗遮挡。

## What's New

- **Refined translation windows** — consolidates legacy translation paths and routes translation requests through the Lens overlay, simplifying window lifecycle handling.
- **Smoother translation flow** — expands the translation window and streamlines quick-translation interactions with fewer window and command branches.
- **More resilient sign-in and networking** — adds multi-domain ABU API failover and improves fallback behavior after authentication failures.
- **Improved macOS overlay stability** — adjusts overlay levels so translation results remain visible around input-method candidate windows.
