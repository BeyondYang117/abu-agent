# ABU Agent Desktop v0.1.5

桌面 AI 助手 · macOS (Apple Silicon + Intel) + Windows。Desktop AI assistant for macOS (Apple Silicon + Intel) and Windows.

## 新版本亮点

- **智能模型路由** —— 根据任务类型与模型能力自动选择更合适的模型，减少重复工具调用。
- **模型权限与订阅控制** —— 支持按模型配置访问权限与订阅层级，云端模型筛选更加准确。
- **聊天并发发送保护** —— 增加发送前置锁，避免同一对话同时发起多个请求。
- **ABU API 请求体验改进** —— 增加自定义 User-Agent 并简化 relay 路由策略请求。
- **本地 CLI 编程模式** —— 支持通过快捷方式更快启动本地 CLI 编程代理。

## What's New

- **Smart model routing** — selects better-fit models by task type and capability while reducing duplicate tool calls.
- **Model access and subscription controls** — configure model permissions by subscription tier with more accurate cloud filtering.
- **Chat concurrency protection** — adds a preflight send lock to prevent overlapping requests in one conversation.
- **Improved ABU API requests** — adds a custom User-Agent and simplifies relay routing-policy requests.
- **Local CLI programmer mode** — adds a shortcut for quickly launching local CLI coding agents.
