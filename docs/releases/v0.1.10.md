- **账号中心与每日签到** —— 增加每日签到入口、签到状态和奖励反馈，完善账号信息展示。
- **账号 API 迁移与兼容** —— 迁移到规范的用户与平台接口，并增强 API-only host、认证失败和网络故障转移处理。

- **Account center and daily check-in** — adds daily check-in access, status, reward feedback, and richer account details.
- **Account API migration and compatibility** — migrates to canonical user and platform endpoints while hardening API-only hosts, authentication failures, and network fallback.
- **Improved account experience** — refines account menus, quota status, and model selection across chat and settings.
